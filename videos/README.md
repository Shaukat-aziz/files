# Videos Directory

Add your video files here. Supported formats:
- MP4 (recommended)
- WebM
- OGG

## Example URLs

After uploading a video file named `tutorial.mp4`, it will be accessible at:
```
https://shaukat-aziz.github.io/files/videos/tutorial.mp4
```

## Best Practices

1. Use descriptive filenames
2. Compress videos before uploading
3. MP4 with H.264 codec is most compatible
4. Consider file size limits (GitHub recommends < 100MB per file)
5. For larger videos, consider hosting on dedicated video platforms
