## Looping

All GIFs in this repository are configured to loop infinitely to ensure continuous playback when displayed in browsers or embedded in documents. When adding new GIFs, ensure they are set to loop forever for the best user experience.

To enable looping on a GIF file, use:
```bash
gifsicle --loopcount=forever input.gif -o output.gif
```

## Best Practices

1. Use descriptive filenames
2. Optimize GIFs to reduce file size (tools: ezgif.com, gifsicle)
3. Ensure GIFs loop infinitely for continuous playback
4. Consider WebM or MP4 for longer animations (smaller file size)
5. Recommended max dimensions: 800x600px
6. Limit frame count for smaller file sizes
