## Best Practices

1. Use descriptive filenames
2. Optimize GIFs to reduce file size (tools: ezgif.com, gifsicle)
3. Consider WebM or MP4 for longer animations (smaller file size)
4. Recommended max dimensions: 800x600px
5. Limit frame count for smaller file sizes
