# Multimedia File Hosting

A simple repository for hosting multimedia files (images, videos, GIFs) that can be linked in PDF documents or other external resources.

## 🌐 Live Website

Once GitHub Pages is enabled, your files will be accessible at:
```
https://[your-username].github.io/files/
```

## 📁 Directory Structure

```
files/
├── images/          # Image files (JPG, PNG, SVG, WebP)
├── videos/          # Video files (MP4, WebM, OGG)
├── gifs/            # Animated GIF files
├── index.html       # Website homepage
├── styles.css       # Website styling
└── README.md        # This file
```

## 🚀 Getting Started

### 1. Enable GitHub Pages

1. Go to your repository settings
2. Navigate to "Pages" section
3. Under "Source", select the branch (usually `main`)
4. Click "Save"
5. Your site will be published at `https://[username].github.io/files/`

### 2. Upload Files

Add your multimedia files to the appropriate folder:

- **Images**: `images/` folder
- **Videos**: `videos/` folder
- **GIFs**: `gifs/` folder

### 3. Get Direct URLs

Once uploaded, your files will be accessible at:

```
Images:  https://[username].github.io/files/images/[filename].jpg
Videos:  https://[username].github.io/files/videos/[filename].mp4
GIFs:    https://[username].github.io/files/gifs/[filename].gif
```

### 4. Link in PDF Documents

Use these URLs as hyperlinks in your PDF documents. Most PDF readers will open the links in a browser, allowing viewers to see multimedia content that can't be embedded directly in PDFs.

## 📝 Example Use Cases

- **Educational Materials**: Link to demonstration videos or diagrams
- **Reports**: Include high-resolution images or animated explanations
- **Presentations**: Reference multimedia content without bloating file size
- **Documentation**: Link to tutorial GIFs or instructional videos

## 🔗 URL Examples

After uploading a file named `example.jpg` to the `images/` folder, access it at:
```
https://[username].github.io/files/images/example.jpg
```

## 💡 Tips

1. **Organize by Project**: Create subfolders within each category
2. **Use Descriptive Names**: Name files clearly (e.g., `tutorial-step1.jpg`)
3. **Keep File Sizes Reasonable**: Optimize images and videos for web use
4. **Test Links**: Always verify URLs work before sharing

## 📋 Supported Formats

- **Images**: JPG, PNG, SVG, WebP, GIF
- **Videos**: MP4, WebM, OGG
- **GIFs**: Animated GIF files
