# files
Repo for hosting files

## GitHub Pages

This repository is set up to be hosted on GitHub Pages.

### How to Enable GitHub Pages

To make this website live, follow these steps:

1. Go to your repository settings on GitHub: `https://github.com/Shaukat-aziz/files/settings/pages`
2. Under "Build and deployment" section:
   - **Source**: Select "Deploy from a branch"
   - **Branch**: Select the branch you want to deploy (e.g., `main`) and the folder (e.g., `/ (root)`)
3. Click "Save"
4. Wait a few minutes for GitHub to build and deploy your site
5. Your site will be available at: `https://shaukat-aziz.github.io/files/`

### Files

- `index.html` - Main entry point for the website
- `.nojekyll` - Disables Jekyll processing for faster deployment
