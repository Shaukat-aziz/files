# Images Directory

Add your image files here. Supported formats:
- JPG/JPEG
- PNG
- SVG
- WebP
- GIF (static)

## Example URLs

After uploading an image file named `example.jpg`, it will be accessible at:
```
https://shaukat-aziz.github.io/files/images/example.jpg
```

## Best Practices

1. Use descriptive filenames (e.g., `tutorial-step1.jpg` instead of `img1.jpg`)
2. Optimize images before uploading (recommended max width: 1920px)
3. Use appropriate formats:
   - Photos: JPG
   - Graphics with transparency: PNG
   - Logos/icons: SVG or PNG
   - Large images: WebP
