📁 Multimedia File Hosting

Host and link images, videos, and GIFs for your PDFs

About This Repository

This repository hosts multimedia files that can be linked in PDF documents. Files are organized by type and can be accessed via direct URLs.

How to Use

1. Upload Files

Add your multimedia files to the appropriate folder: images/, videos/, or gifs/

2. Get Direct URL

Access files using: https://username.github.io/files/[folder]/[filename]

3. Link in PDF

Use the direct URL as a hyperlink in your PDF documents
